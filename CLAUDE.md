# Мод «Лжедмитрий I» для Age of Empires II: Definitive Edition

Короткая кампания из 3 миссий о Лжедмитрии I (1604–1606): «Через границу», «Новгород-Северский и Добрыничи», «Москва». Ключевая механика: города переманиваются монахами и агитацией (конверсия), а не берутся штурмом. Свои юниты и технологии: польский гусар-наёмник, казак-перебежчик, «Царевич», «Польский контракт».

Язык проекта: русский.

## Маршрутизация работы (главная сессия = диспетчер)

Субагенты не могут запускать других субагентов, поэтому распределяет работу главная сессия. Порядок:

1. **story-architect** (Opus): сюжет, структура миссий, вступления и финалы.
2. **historian-checker** (Opus): проверка фактов. Запускать после каждого сюжетного текста и до сборки сценария.
3. **mission-designer** (Sonnet): спецификация миссии, юниты, технологии, баланс.
4. **dialogue-clerk** (Haiku): реплики, подписи, названия, мелкие правки JSON.
5. **scenario-builder** (Sonnet): Python-скрипты и сборка `.aoe2scenario`. Единственный, кто работает со сценариями.
6. **scenario-verifier** (Sonnet, только чтение): независимая проверка собранного сценария после каждой сборки.

Команды: `/new-mission`, `/build-mission <номер>` (сборка и сверка), `/install-scenario <файл>` (копирование в папку игры без перезаписи).
Python из `.venv` запускай только с `-I -X utf8` (хук `check_python_flags.py` иначе блокирует).

Независимые задачи запускай параллельно (например, реплики для разных миссий). Историческая проверка обязательна перед сборкой.

## Структура
- `missions/` — описания и спецификации миссий, `history-review.md`.
- `data/` — `units.json`, `techs.json` и другие данные мода.
- `scripts/` — скрипты сборки сценариев.
- `build/` — собранные сценарии (в git не коммитятся).

## Жёсткие правила
- Файлы `*.aoe2scenario` не правятся вручную, только скриптами (хук блокирует запись).
- Оригинальные файлы игры (`C:\Program Files (x86)\Steam\steamapps\common\AoE2DE`) не менять.
- Локальные моды лежат в `%USERPROFILE%\Games\Age of Empires 2 DE\<STEAM_ID>\mods\local\`; копировать туда только по просьбе пользователя.
- Неподтверждённые факты помечаются `[ПРОВЕРИТЬ: ...]`.
