# Установка сценария $ARGUMENTS

Папка сценариев игры: `%USERPROFILE%\Games\Age of Empires 2 DE\<STEAM_ID>\resources\_common\scenario\`

## Шаги
1. Проверь, что файл `build/$ARGUMENTS` существует и не пустой.
2. Проверь, есть ли в папке сценариев файл с таким именем.
   - Если есть и содержимое совпадает по SHA256, ничего не копируй, скажи, что уже установлено.
   - Если есть и отличается, НЕ перезаписывай и не удаляй. Предложи новое имя с суффиксом версии (например `_v2`) и спроси пользователя.
   - Если нет, скопируй как новый файл.
3. После копирования сравни SHA256 исходника и копии.
4. Файлы самой игры (`C:\Program Files (x86)\Steam\...`) не трогай.

## Запуск (сообщи пользователю)
1. Игра, Редактор сценариев.
2. Открыть сценарий по имени.
3. Нажать «Тест».

## Отчёт
Что скопировано и куда, хеши, что не проверено (запуск в игре).
