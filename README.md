# Лжедмитрий I: кампания для Age of Empires II: Definitive Edition

Фанатская мини-кампания о Лжедмитрии I (Смута, 1604–1606), сделанная как набор сценариев для редактора AoE2 DE. Сейчас готова миссия 1 «Через границу».

> Неофициальный фанатский проект. Не связан с Microsoft, World's Edge и Xbox Game Studios. В репозитории нет файлов самой игры.

## Как запустить миссию 1
1. Скачайте файл сценария из папки `dist/` (`01_cherez_granitsu_v3.aoe2scenario`).
2. Положите его в папку пользовательских сценариев игры:
   `%USERPROFILE%\Games\Age of Empires 2 DE\<ваш Steam ID>\resources\_common\scenario\`
3. Игра → **Редактор сценариев** → откройте сценарий → **Тест**.

Сценарий не требует модов данных. Юниты «Стрелец» и «Боярин» сделаны переименованием и настройкой существующих через триггеры.

## Что внутри
- `dist/` — готовые сценарии.
- `missions/` — сюжет, дизайн, реплики, историческая сверка (`history-review.md`).
- `data/` — данные юнитов и технологий.
- `scripts/` — скрипты сборки сценариев на Python ([AoE2ScenarioParser](https://github.com/KSneijders/AoE2ScenarioParser)) и превью карты.
- `.claude/` — настройки агентов и хуков для работы с Claude Code.

## Статус и честные оговорки
- Сценарий собран скриптами и проверен парсером. Часть механик (цветные теги реплик, поведение новых триггеров, найм бояр) в самой игре пока проверяется.
- История: сюжет максимально близок к фактам, но есть условности (например, броды на Десне, каменные стены вместо деревянных, вылазки), они помечены в `missions/history-review.md`.
- Озвучки пока нет, реплики текстовые.

## Сборка из исходников
```
python -m venv .venv
.venv\Scripts\python.exe -m pip install AoE2ScenarioParser Pillow
.venv\Scripts\python.exe -I -X utf8 scripts\build_01_v3.py
```
